# 智能水下清洁机器人控制系统 V1.0（上位机 · 监控大屏版）

面向**水下清洁机器人远程操控**的 PySide2 上位机软件。启动后进入**单页监控大屏**：
顶部标题栏（在线/时间/通知）＋ 左侧导航与系统状态 ＋ 主区九宫格面板
（实时画面/CAM、设备状态、运动控制摇杆、任务信息、导航路径、传感器数据、
推进器输出柱图与告警信息流）。控制仍严格对齐郑莹莹软著：只连接 91 主控
`192.168.1.91:12345`，指令为 7 字段 ASCII（含灯光），89 灯光从控由 91 自动转发。

> 数据说明：连接/视频/指令/推进器输出为真实；深度/姿态/水温/舱内环境等遥测
> 当前无下位机上报源，界面显示「模拟」并在告警信息流记录，接入真值时替换
> `dashboard.py` 中 `SimTelemetry` 即可（协议新增后统一解析）。

使用方式与指令协议详见下文（沿用“单主控连接/控制方法”各节）。

## 单主控连接（按软著）

| 项目 | 软著设定 |
|---|---|
| 主控节点（界面“主控连接”） | `192.168.1.91:12345` —— 指令 + 水下视频 + 状态 |
| 89 从控 | `192.168.1.89:12346` —— **灯光从控**，由 91 收到指令后自动转发（上位机不需连接） |
| 电脑网卡 | 建议固定 `192.168.1.99`（子网 255.255.255.0） |

## 控制方法（对齐软著）

- 模式：`10`=启动相机并运行（采集+执行），`00`=停止相机并待机
- 控制指令：`10 90 1,-1 180,180 101 60 80`（7 字段，含灯光），发到 91 主控；
  91 执行并把灯光值转发给 89（数字字符串，端口 12346）
- 参数限幅：舵机 0~180 / 推进器 PWM 0~255（映射 0~100%）/ 刷速 0~100 / 灯光 0~100

## 功能一览

| 页面 | 功能 |
|---|---|
| 首页监控 | 水下视频（91 主控 4字节长度+JPEG 帧流）、推进器速度波形、节点/帧率/指令数/运行时长监测 |
| 作业控制台 | 模式(10启动/00待机)、双推进器方向+PWM(0~255)、舵机(0~180)、三路清洗刷+转速%、LED 灯光(0~100)、急停 |
| 指令调试 | 发送记录/系统日志；可手输任意 7 字段指令（含 `0000` 断开） |

安全保护：所有参数按说明书限幅（舵机0~180、PWM0~255、刷速/灯光0~100）；
“急停”发送 `00 90 0,0 0,0 000 0 0` 全系统安全停机。
连接意外断开时按 `config.json → system` 设置自动重连（默认每 3s 一次，最多 10 次）。

推进器安装方向：若你们的机器是**两推进器同向安装**（前进=双正转），无需改动；
若**右推进器镜像安装**（与使用说明书示例 `10 90 1,-1 180,180 ...` 对应，前进=左正转+右反转），
把 `config.json` 中 `robot91.thruster_layout` 改为 `"mirror"`。

## 指令协议（7 字段，与软著《源代码》一致）

```
MODE ANGLE d1,d2 s1,s2 BRUSH_STATE BRUSH_SPEED LIGHT
例: 10 90 1,-1 180,180 101 60 80
    00 0  0,0  0,0    000          0          0
0000 = 断开连接
```
- MODE：`10` 启动运行（开始采集并执行），`00` 停止待机
- ANGLE：舵机 0~180；`d1,d2`：推进器方向 -1/0/1；`s1,s2`：PWM 0~255
- BRUSH_STATE：3 位 01（三路清洗刷）；BRUSH_SPEED：0~100%；LIGHT：0~100%

> 说明：软著《使用说明书》示例写了 6 字段（示例未带灯），但《源代码.doc》的
> 指令解析统一按 7 字段含灯实现，因此本上位机默认发 7 字段；若真机为 6 字段固件，
> 用 `robot_protocol.py` 的 `cmd_to_9_12_style()` 裁掉灯字段即可。

```
预览_*.png            界面预览图
```

## 质量自检

环境就绪后运行（无需显示器、无需真机）：

```
python self_check.py        # 协议单测 + 模拟91回路
python self_check.py --gui  # 追加离屏 GUI 冒烟
```

退出码 0 表示全部通过。

## 运行（无真机联调：本地模拟）

1. 双击 `安装依赖.bat`（自动建 `.venv` 并装 PySide2/pyqtgraph/opencv）。
2. 双击 `启动模拟91服务器.bat` —— 监听 `127.0.0.1:12345`，持续下发合成水下视频帧
   （想同时模拟 89：另开一个窗口执行 `python mock_pi91_server.py --port 12346`）。
3. 双击 `启动上位机.bat`：
   - 91 框填 `127.0.0.1:12345`；
   - 89 框填 `127.0.0.1:12346`（仅演示用，平时可留默认不连）；
   - 点“一键连接 91+89”或分别连接。

连接成功后：
- 首页监控“视频源”下拉可在 91/89 间切换，点“打开视频显示”观看画面（含执行状态回显）；
- 右侧监测面板实时显示节点在线状态、视频帧率、指令数、运行时长；
- 在作业控制台拖动舵机/灯光、点刷子、按方向键，右侧状态与模拟画面同步变化；
- “指令调试”页可选择发到 91 或 89，手输 `10 90 1,-1 180,180 101 60 80` 等原始指令；
- 点“保存截图”把当前帧存到 `data/`。

## 真机联调（展会）

1. 电脑网卡设固定 IP（建议 `192.168.1.99`，子网 255.255.255.0）；
2. 树莓派 91（`192.168.1.91:12345`）与 89（`192.168.1.89:12345`）通电并运行各自服务；
3. 双击 `启动上位机.bat`，默认已填两个真机地址，点“一键连接 91+89”；
4. 视频源切到对应节点，“打开视频显示”即可展示现场水下摄像头画面；
   运动/舵机/刷子/灯光面板在真机可用时即可操作（展会也可只展示监控画面）。

## 协作开发

- **环境**：他人可直接 `pip install -r requirements.txt`，不必依赖 `安装依赖.bat`；
  `.venv`、`logs/`、`data/`、`config.json` 已 git 忽略。
- **配置**：复制 `config.example.json` 为 `config.json`，按自己机器改地址/推进器朝向。
- **入口唯一**：正式运行以 `main.py → dashboard.py`（单页大屏版）为准；`underwater_window.py`
  仅作对软著参考，其视频接收线程已抽到公共组件 `video_receiver.py`。
- **协议是契约**：改通信格式务必同步 `robot_protocol.py` 与本文档；提交前跑 `python self_check.py`。
- **流程**：每个人在独立分支开发，`git pull` 后再改，合回主分支走合并/评审；按
  协议/GUI/节点/工具 模块划分职责。
